# Full project quality assurance

**Complexity:** 🔴 **Complex** — full-stack validation with external Supabase and AI provider dependencies.

## Objective

Exercise the application as an end user, fix safe defects found during testing, and leave a simple, repeatable way to launch the project locally.

## Tasks

1. Validate static quality gates: backend tests, dependency consistency, frontend build and lint.
   - **Validation:** all commands exit successfully.
2. Start the FastAPI app with non-sensitive local configuration and test its health endpoint.
   - **Validation:** `GET /health` returns HTTP 200 and `{ "status": "ok" }`.
3. Start the frontend and test visual routing/authentication in a browser.
   - **Validation:** the application renders and protected routes redirect unauthenticated users to `/auth`.
4. If working Supabase and provider configuration is available, test sign-in, chat, upload, ingestion status and retrieval end-to-end without exposing secrets.
   - **Validation:** each user flow reaches its expected terminal state.
5. Add an easy one-command local launcher and a concise test command reference.
   - **Validation:** the launcher starts both services and the documented checks run.
